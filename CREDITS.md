# Credits

## Word list

`src/words.txt` is generated by `tools/build_words.py` from:

- **wordfreq** by Robyn Speer — word frequency ranking. Code Apache-2.0; data CC BY-SA 4.0.
  <https://github.com/rspeer/wordfreq>
- **SCOWL / Hunspell en_US dictionary** (en-wl/wordlist, release 2026.02.25) — keeps only lowercase
  dictionary words, so names and most abbreviations drop out. Permissive SCOWL licence.
  <https://github.com/en-wl/wordlist>
- **List of Dirty, Naughty, Obscene, and Otherwise Bad Words** (LDNOOBW, English) — offensive-word
  blocklist. CC BY 4.0. <https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words>

Plus a hand-made blocklist in the script (abbreviations, names, and terms that don't suit a cartoon game).

To rebuild: install wordfreq in a throwaway environment, download the two lists, then

```
python -I tools/build_words.py --dic en_US.dic --aff en_US.aff --blocklist en --out src/words.txt
```
